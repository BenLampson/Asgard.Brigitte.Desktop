# 1.0.24 release notes

## 简体中文

- 本机工作区的单条和批量修复提示词要求在建议将 BUG 标为阻塞时，说明卡点、谁需要做什么、怎样确认阻塞已解除，以及接下来从哪一步继续。

## English

- When a fix is blocked, prompts for individual bugs and batches in local workspaces now ask the AI to explain what stopped progress, who needs to act, how to verify the blocker is resolved, and where to resume.
