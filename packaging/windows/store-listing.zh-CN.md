## 产品名称

Asgard Brigitte

## 简短说明

通过项目看板、实时动态、Markdown 和 MCP 工作流，让团队的 BUG 协作更清晰。

## 描述

Asgard Brigitte 是用于团队报告、跟踪和处理软件 BUG 的桌面工作区。需要账号、网络连接及兼容的 Brigitte 服务；桌面客户端不包含可独立运行的本地服务器或 AI 模型。

把项目与 BUG 放在同一个工作区。自由切换看板和列表，按标题或内容搜索，按状态和优先级筛选，并在独立窗口打开详情或编辑器。通过问题描述、回复、处理记录、状态历史及附件，让每一次修复从发现到回归都有迹可循。

创建自己的项目，或通过邀请链接加入团队。项目负责人可以管理成员，生成带可选密码和有效期的邀请；实际访问范围与管理能力由服务权限决定。

实时同步协作变化，在本地读取已同步记录，通过未读动态与系统托盘跟进进展。连接中断时，已同步内容保持只读。关闭主窗口时，可以选择退出程序或继续在托盘运行。

复制修复提示词，或为兼容的外部工具创建带权限范围的 MCP Key。复制提示词不会自动把数据发送给 AI 提供方；外部 AI 工具和 MCP 客户端需要单独配置和使用。

界面支持简体中文与英文，默认跟随操作系统，可在设置中随时切换；同时支持白天、晚间和跟随系统主题。

桌面客户端采用 Apache-2.0 开源。文档、隐私说明、故障反馈和功能建议统一放在 GitHub。获得源码不代表获得私有服务或任何项目数据的访问权限。

## 产品功能 — 每行填写一项

- 项目 BUG 看板和列表，支持搜索与条件筛选
- BUG 详情、编辑、回复及项目管理的独立窗口
- Markdown 描述、处理记录、状态历史与附件
- 带可选密码和有效期的项目邀请链接
- 实时同步，连接中断时只读查看已同步内容
- 系统托盘、未读动态及系统通知数量提示
- 复制修复提示词，管理外部工具使用的 MCP Key 与权限范围
- 简体中文和英文，默认跟随系统语言并可手动切换
- 白天、晚间、系统主题和持久保存的设备偏好
