## 产品名称

Asgard Brigitte

## 简短说明

不登录也能离线管理 BUG，支持项目看板、Markdown、评论、状态和附件。

## 描述

Asgard Brigitte 是用于报告、跟踪和处理软件 BUG 的桌面工作区。启动后选择“本机使用”，无需注册、登录、联网或部署服务器。项目、BUG、回复、处理记录、状态历史及附件正文保存在这台电脑，重启后仍可继续使用。

把项目与 BUG 放在同一个工作区。自由切换看板和列表，按标题或内容搜索，按状态和优先级筛选，并在独立窗口打开详情或编辑器。通过问题描述、回复、处理记录、状态历史及附件，让每一次修复从发现到回归都有迹可循。

在线团队协作为可选功能，需要账号、网络、兼容的 Brigitte 服务及 Heimdall 登录。在线模式可以创建项目、通过邀请链接加入团队，由项目负责人管理成员及带可选密码和有效期的邀请，权限由服务端决定。本机和在线工作区相互独立，本机记录不会自动上传或合并；不包含局域网共享。

本机模式在断网时仍能完整读写。在线模式通过实时同步、未读动态与系统托盘跟进团队变化，连接中断时已同步的在线内容保持只读。关闭主窗口时，可选择退出或继续在托盘运行。每次启动都保留本机使用和在线登录入口。

本机模式可复制包含实际问题快照的修复提示词；在线模式继续使用服务端模板。复制不会自动把数据发送给 AI 提供方。带权限范围的 MCP Key 为在线模式专用，外部 AI 工具需自行配置；应用不内置 AI 模型。

界面支持简体中文与英文，默认跟随操作系统，可在设置中随时切换；同时支持白天、晚间和跟随系统主题。

桌面客户端采用 Apache-2.0 开源。文档、隐私说明、故障反馈和功能建议统一放在 GitHub。获得源码不代表获得私有服务或任何项目数据的访问权限。

## 产品功能 — 每行填写一项

- 项目 BUG 看板和列表，支持搜索与条件筛选
- 无需注册、登录或部署服务，完整离线本机使用
- 项目、BUG、回复、状态历史与附件正文保存在本机
- BUG 详情、编辑、回复及项目管理的独立窗口
- Markdown 描述、处理记录、状态历史与附件
- 在线模式提供带可选密码和有效期的项目邀请
- 在线实时同步，断线时只读查看已同步在线内容
- 系统托盘、未读动态和按项目配置的提醒，支持变更类型与目标状态筛选
- 本机修复提示词，以及在线模式专用的 MCP Key 管理
- 简体中文和英文，默认跟随系统语言并可手动切换
- 白天、晚间、系统主题和持久保存的设备偏好
