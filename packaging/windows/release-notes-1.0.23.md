# 1.0.23 release notes

## 简体中文

- 离线 HTML BUG 报表支持分页。点击状态、优先级、涉及组件、提出人或每日提交量折线图上的日期，即可筛选明细；筛选条件可叠加。
- 明细新增涉及服务 / 组件和提出人。报表时间与每日统计统一使用导出设备的本地时区。
- 在线工作区根据当前账号的项目权限显示创建和邀请入口。

## English

- Offline HTML bug reports now paginate the details. Click a status, priority, component, reporter, or day in the daily submissions chart to filter the table. Filters can be combined.
- The details show affected services or components and the reporter. Timestamps and daily totals use the local time zone of the device that exports the report.
- The online workspace shows project creation and invitation actions based on the current account's permissions.
