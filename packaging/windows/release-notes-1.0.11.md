# Microsoft Store release notes 1.0.11

## English

Read replies and work logs newest first, expand each record independently, and see structured handoff details. Project notification settings filter unread activity while tray BUG statistics remain visible. Configure lane order per project with drag and copy. Device preferences now use SQLite.

## 简体中文

回复和处理记录按最新在前显示，可分别展开或收起，处理记录清楚区分摘要和交接事项。未读动态遵循项目提醒设置，托盘继续显示 BUG 数量。支持按项目拖拽或复制泳道顺序。本机偏好改用 SQLite 保存。
