# Microsoft Store release notes 1.0.11

## English

Read replies and work logs newest first, expand each record independently, and see structured handoff details. Mute project activity in the tray and unread list. Configure lane order per project with drag and copy. Device preferences now use SQLite.

## 简体中文

回复和处理记录按最新在前显示，可分别展开或收起，处理记录清楚区分摘要和交接事项。静默项目不再在托盘和未读动态中显示提醒。支持按项目拖拽或复制泳道顺序。本机偏好改用 SQLite 保存。
