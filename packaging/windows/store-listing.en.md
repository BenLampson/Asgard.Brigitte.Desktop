## Product name

Asgard Brigitte

## Short description

Track bugs together with project boards, live updates, Markdown, and MCP workflows.

## Description

Asgard Brigitte is a desktop workspace for reporting, tracking, and resolving software bugs with your team. An account, internet connection, and access to a compatible Brigitte service are required. The desktop client does not include a standalone local server or an AI model.

Keep projects and bugs in one place. Move between board and list views, search by title or content, filter by status and priority, and open details or editors in separate windows. Record descriptions, replies, work logs, status changes, and attachments so your team can follow a fix from discovery to regression checks.

Create your own projects or join a team through an invitation link. Project owners can manage members and create invitations with optional passwords and expiration. Access and administrative functions follow the service's permissions.

Stay up to date with live synchronization, local reading of synchronized records, unread activity, and a system tray. When disconnected, already synchronized content remains read-only. You can choose whether closing the main window quits the application or keeps it running in the tray.

Copy repair prompts or create scoped MCP keys for compatible external tools. Copying a prompt does not automatically send data to an AI provider. External AI tools and MCP clients are configured and operated separately.

The interface supports English and Simplified Chinese, follows your operating system by default, and can be changed in Settings. Light, dark, and system themes are also available.

The desktop client is open source under Apache-2.0. Documentation, privacy information, bug reports, and feature requests are available on GitHub. Source availability does not grant access to private services or project data.

## Product features — one entry per line

- Project bug boards and list views with search and filters
- Separate windows for bug details, editing, replies, and project management
- Markdown descriptions, work logs, status history, and attachments
- Project invitations with optional passwords and expiration
- Live synchronization and read-only access to already synchronized content during interruptions
- System tray, unread updates, and desktop notification counts
- Copyable repair prompts and scoped MCP key management for external tools
- English and Simplified Chinese with automatic system-language selection
- Light, dark, and system themes with saved device preferences
