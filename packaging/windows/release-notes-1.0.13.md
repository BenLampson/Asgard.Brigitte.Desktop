# English

Work records now show the titles of related bugs alongside their IDs when the bugs are available in the same project. Author and owner names are shown with their IDs; unavailable names are clearly labeled. Existing records and statuses are preserved.

# 简体中文

处理记录现在会为同一项目中可匹配的关联反馈显示标题和完整 ID。作者和负责人同时显示名称与 ID；无法取得名称时会明确提示。已有记录和状态保持不变。
