# 1.0.5.0 商店更新说明

## 简体中文

- 新增本地泳道排序，可调整状态泳道顺序并恢复默认顺序。
- 状态筛选支持多选，修复筛选标签、复选框与键盘焦点的样式问题。
- 支持待部署、待人工回归和人工回归通过流程，历史处理记录保留原有含义。
- 增加客户端版本及能力标识，改善与服务端的兼容性。
- 完善单个修复、批量修复与 MCP 配置引导，明确调用参数、续锁、失败处理和人工验收边界。

## English (United States)

- Customize the local order of status lanes and restore the default order.
- Filter by multiple statuses, with improved checkbox, tag and keyboard focus styling.
- Support deployment and human regression verification stages while preserving the meaning of historical records.
- Include client version and capability identifiers for improved server compatibility.
- Clarify individual and batch repair prompts and MCP setup guidance, including parameters, lock renewal, failure handling and human verification.
