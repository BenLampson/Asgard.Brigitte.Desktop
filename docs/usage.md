# 使用说明

简体中文 · [English](usage.en.md)

## 默认本机使用

每次启动显示欢迎页，“本机使用”是默认主入口，同时保留在线登录入口。本机使用无需账号或联网，支持项目、BUG 看板与筛选、编辑、状态、回复、处理记录、领取锁、附件添加与预览下载、删除和复制修复提示词。数据与附件正文保存在本机，重启后继续使用。

从左下角“本机用户”菜单选择“返回启动页”可再选择在线登录；此操作保留本机数据。两种工作区独立，不自动上传或合并。本机模式不提供项目邀请、在线账号管理、远程 MCP Key 或局域网共享。本机提示词包含问题快照，可自行交给 AI 工具，不指向线上 MCP。

## 在线登录与项目

打开客户端后，登录会跳转系统浏览器，通过 Heimdall 完成身份验证，再通过本机回调返回应用。服务开放注册时，可以从欢迎页进入注册。注册入口和账户策略由服务方管理。

首次登录先同步有权限的工作区。没有项目时，可在“我的项目”中创建项目，或粘贴邀请链接加入已有项目。项目负责人可以调整项目资料、管理成员和邀请；其他成员按服务端授权协作。客户端不会因为源码公开而获得额外权限。

邀请链接可带单独密码与有效期。创建时保存好完整链接，关闭结果窗口后不再展示原始令牌。接收者粘贴链接，查看项目摘要并确认加入；有密码时另行输入。邀请的创建、查看、撤销和加入都需要联网。

## 日常协作

看板支持搜索、状态、优先级、来源和负责人筛选。BUG 提交、详情、编辑、回复和状态操作使用独立窗口，保留主看板上下文。附件可选择、拖入或粘贴图片；元数据随同步更新，正文在预览或下载时按需请求。

在线模式从本地 SQLite 投影读取已提交的数据。修改先提交在线 API，再等待 WebSocket 确认落库；不要在“已保存，等待同步”时重复提交。在线模式运行期间断网会保留已同步内容供阅读，并禁用在线命令。重新启动或切换账号后，选择在线入口并完成线上身份确认及首批同步才能进入在线工作区。本机模式直接保存到独立本机库，不受这些同步条件限制。

## 窗口、主题与通知

Windows 同一用户、同一桌面会话只运行一个实例，再次启动会聚焦已有主窗口。首次关闭时可选择退出或最小化到托盘，也可以记住选择，之后在“设置”中调整。

最小化到托盘后仍同步并接收通知；显式退出程序会停止。前后台通知都提供项目名、BUG 标题、操作人及变化摘要，不主动截短名称。Windows 超长正文分条发送；系统横幅可能折叠文字，完整内容可在托盘未读动态中查看。托盘显示未读动态，可单条或全部标记已读。系统通知行为仍受操作系统授权及免打扰设置影响。

在“设置 → 提醒设置”按项目控制前台弹窗和系统通知。默认规则适用于所有未单独配置的项目，也自动适用于新项目；可以先关闭默认提醒，再搜索并选择关注的项目，取消“使用默认规则”后单独开启。每套规则均可选择新建 BUG、状态变化、领取与负责人、资料、回复、附件、项目变化及 BUG 移出工作区。状态变化可按目标状态筛选，例如仅提醒“已处理”和“已关闭”；只关心状态时请取消其他变更类型，同批次任一类型匹配都会提醒。重新勾选“使用默认规则”即可移除项目覆盖。

提醒设置修改后自动保存在这台设备，按服务、租户与账号隔离，重启后仍然生效。关闭提醒不影响同步和完整未读动态，不会改变其他成员的设置，也不会补弹之前已静默的通知。本机工作区没有在线动态提醒。

白天、晚间和跟随系统主题会同步到应用窗口。项目侧栏可拖动调整宽度。主题、侧栏和关闭偏好保存在此设备。

在“设置 → 普通设置 → 语言”选择“跟随系统 / 简体中文 / English”。默认跟随操作系统，中文系统语言使用简体中文，其余使用英文。语言偏好保存在设备上，切换会即时更新已打开的窗口，保留编辑草稿，项目名、BUG 正文、评论及服务端提示词保持原文。

## AI 协作

可复制单条 BUG 或项目级修复提示词，交给自己选择的 AI 工具。复制本身不会调用模型或上传第三方 AI 服务。MCP Key 用于授权外部客户端访问服务，权限由服务端约束；不要把 Key 发到公开 issue、截图或仓库中。

## 退出

退出登录会删除当前设备保存的登录凭据、关闭业务子窗口，并清理当前会话的内存数据。它不会删除服务端协作内容，也不承诺删除磁盘上的工作区缓存。更多信息见[隐私与本地数据](data.md)。

正式[隐私政策](../PRIVACY.zh-CN.md)和[支持说明](../SUPPORT.zh-CN.md)已公开。普通问题和功能建议请[提交 GitHub Issue](https://github.com/BenLampson/Asgard.Brigitte.Desktop/issues/new/choose)，请先移除凭据和私有资料。

## 创建日期与应用更新

看板和列表可按创建日期范围筛选，起止日期均包含当天，按设备本地时区解释。数据保留 UTC，查询边界在本机转换；筛选不请求服务器。

商店安装版在启动和运行期间每天检查更新，设置内也可手动检查。发现更新后可立即安装或延后一天提醒；安装前请保存所有窗口的草稿。便携版和其他非商店安装来源需从原渠道获取新版。
