# Asgard Brigitte 1.0.12

Windows x64; Microsoft Store package version `1.0.12.0`. This version is being prepared and has not yet been submitted to the Store.

- Settings now use a grouped navigation sidebar for general preferences, appearance, project board lanes, notifications and app updates. Project notification rules retain their default inheritance, searchable project selection and destination-status filters.
- Replies and work records start collapsed, with independent expand controls and summaries. Record authors show the associated account; the AI label is identified as a source marker rather than a detected model.
- Unassigned cards show the owner clearly in both Chinese and English. Retired workflow lanes no longer appear in active board or notification settings; existing history remains readable.
- Windows title bar colors are reapplied during window creation and activation to keep the caption controls aligned with the selected theme.

An online server may require a minimum desktop version. Existing local data remains on the device; retired local bug states are moved to a review-needed state without claiming deployment or human verification.

Store certification, Store-signed installation and native runtime acceptance are separate from local build and browser checks. See the [Store submission log](../../packaging/windows/store-submission.md) for the latest confirmed distribution status.
