# Asgard Brigitte 1.0.21

Online project boards show the project's attachment storage usage and quota. Deleting an attachment asks for confirmation and explains that it is permanently deleted; usage refreshes as attachments change. Project storage is managed by the service administrator. Local workspaces do not use online storage quotas.

在线项目看板显示项目附件空间用量和额度。删除附件前会提示永久删除；附件变化后刷新用量。项目空间由服务管理员管理，本机工作区不使用在线额度。

The Windows Store package is unsigned for Partner Center submission; Store availability depends on Microsoft certification. Online storage requires a compatible server.
