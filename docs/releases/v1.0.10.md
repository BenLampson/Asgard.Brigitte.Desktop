# Asgard Brigitte 1.0.10

Windows x64; Microsoft Store package version `1.0.10.0`.

## Changes

- Repair guidance asks for a short, plain-language summary first, followed by complete technical handoff details. Local repair prompts include this structure in English and Simplified Chinese; online prompts are supplied by the connected service.
- Markdown preserves ordinary line breaks in bug descriptions, replies, work logs, history and editor previews. Blank lines, headings, lists, tables and fenced code blocks retain their Markdown structure.
- Drag a bug card directly into the Closed lane from any status, or close it from the status window, while required explanations, work locks and access checks remain in place. Closing a bug does not create a human-verification record.

## Validation and distribution

Local tests use synthetic records, isolated temporary SQLite databases and offline transports. Windows package validation, Microsoft certification, Store-signed installation/upgrade and native runtime acceptance are separate checks; package generation does not establish those results.

All 246 local Core/UI tests passed, including direct card closure from every source status, local history persistence, work-lock behavior, Markdown line breaks, tables, code blocks and safe rendering.

The Store upload MSIX is unsigned for Microsoft to sign. A portable archive must be fully extracted before running the executable and requires Microsoft Edge WebView2 Runtime. No new app capability or database migration is introduced by these client changes.

Exact package checksums and the clean source revision are recorded with the release artifacts. The final Store submission status is recorded in [the submission log](../../packaging/windows/store-submission.md).
