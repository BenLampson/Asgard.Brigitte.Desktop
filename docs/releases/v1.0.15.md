# Asgard Brigitte 1.0.15

Bug status history now shows the newest change first in both local and online workspaces.

The [GitHub release](https://github.com/BenLampson/Asgard.Brigitte.Desktop/releases/tag/v1.0.15) provides the Windows x64 portable ZIP, an unsigned Store-upload MSIX, checksums and source manifest. Extract the full portable archive before running it; Microsoft Edge WebView2 Runtime is required. The unsigned MSIX is for Store submission, not direct installation.

Both packages were built locally from clean, pushed commit `850540efbee730589ef9673ee009468d602f87bd`, tagged `v1.0.15`. The portable ZIP SHA-256 is `86458faf863d3867fe287943db3dfff2dbf1e4db41ac86ffaae6b330d2bb700d`; the MSIX SHA-256 is `5a475bfcfe7c25707f9161aaa50267ab0d8b356647f0d257a88a2dd7cc0d2aeb`. Package identity and the matching Core assembly were checked.

All 284 local Core/UI tests passed, and an isolated SQLite check verified newest-first ordering in local and online projections. The source [Windows/Linux CI run](https://github.com/BenLampson/Asgard.Brigitte.Desktop/actions/runs/41442498795) passed. Store-signed installation or upgrade, Windows App Certification Kit, and native desktop acceptance were not performed for this candidate. The optional symbol package was not generated because `mspdbcmf.exe` was unavailable.

Microsoft Store submission 14 for 1.0.14 was still in certification when checked on November 2, 2026. Its submission was left intact; 1.0.15 has not yet been submitted to the Store. See the [Store submission log](../../packaging/windows/store-submission.md) for status.
