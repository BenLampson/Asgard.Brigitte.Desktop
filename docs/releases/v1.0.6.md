# Asgard Brigitte 1.0.6

Prepared October 23, 2026 (Asia/Shanghai). Windows x64, Microsoft Store package version `1.0.6.0`.

## Changes / 改动

- Drag board lane headers directly to reorder; remove the separate arrow-based sorting panel.
- Show a drop insertion line, scroll near either board edge, and cancel with Escape.
- Support Alt + Left / Right on focused headers and reset from the toolbar.
- Preserve existing local preferences and the full order when status filters hide lanes.
- Hide empty legacy lanes and status filters while retaining local historical records and explicit selections.
- 泳道标题直接拖拽排序，显示落点并支持边缘滚动；取消拖拽不保存。保留键盘调整、恢复默认及本机账号和项目的已有偏好。

## Local verification / 本地验证

- All 195 desktop Core/UI tests passed in Release, including drop insertion in both directions, invalid/no-op drops, filtered order preservation, preference persistence, board/list switching, and historical lane/filter visibility.
- A temporary loopback-only Blazor host exercised the actual `LaneOrder` component, production CSS/JS, and a separate test preference file. Browser checks passed for native mouse dragging and saved order after reload, keyboard movement, edge scrolling, Escape cancellation, filtered dragging without losing hidden lanes, and resetting the order.
- Dark and light layouts were inspected, including a smaller window. Screenshots are local, ignored verification artifacts under `output/playwright/lane-drag/`.
- Windows MAUI/MSIX compilation succeeded. The SDK warned that the optional symbols package was not generated because `mspdbcmf.exe` is unavailable.

## Release scope / 发布范围

The client update requires no backend deployment or SQLite schema migration. It does not automatically change historical BUG statuses. An independently authorized administrative migration of online historical records is separate from the application update; local historical records remain visible while present.

Partner Center confirmed on October 23 that Submission 5 is published. Submission 6 (`1152921505702209958`) was created for version `1.0.6.0`. Source changes from the previous workflow update are included in this release rather than discarded. Native Store installation/upgrade and WACK were not performed.

The final upload package must be rebuilt from the clean source commit after this release checkpoint. Package digest, source revision, and Partner Center result will be recorded after that build and submission. Existing local candidate digests are superseded when the final source package is generated.
