# Asgard Brigitte 1.0.3

Prepared October 20, 2026. Windows x64, MSIX version `1.0.3.0`.

- Fix the board layout when switching back from list view.
- Add clickable status tags with counts for all 15 statuses, with light/dark colors and wrapping at smaller window sizes. Counts respect the other active filters; click a selected tag again to clear it.
- Filter by inclusive creation dates in the device's local time zone using the local SQLite workspace. UTC storage and the service API remain unchanged.
- Check Microsoft Store installations for updates at startup, daily while running, and manually in Settings. Save all drafts before choosing to install; reminders can be snoozed for one day.
- Show detailed background notifications instead of update counts. Preserve full project names, bug titles, and actors; split long Windows notification payloads without dropping text. Windows may still collapse banner text, while full summaries remain in the app.
- Update bilingual privacy disclosures to reflect detailed system notifications.

Deletion behavior is unchanged. This desktop release requires no service deployment or database migration. Store certification and customer availability are separate from package build and submission.

## Final candidate update — October 20, 2026

- Keep the search toolbar compact. Status tags and additional filters expand into full-width rows below it; active filter counts remain visible when collapsed.
- Fix the status parameter binding, accidental text selection on filter controls, and date control alignment.
- Correct the welcome character's arm joints, hammer trajectory, grip orientation and hair/head synchronization. Clicking the character plays one cycle; loading continues to animate automatically. Impact highlights and sparks appear together only at the strike.
- Validation: 130 client tests passed. Windows x64 portable build passed. Animation geometry was sampled offline; native installation/upgrade and WACK have not been rerun for this candidate.
