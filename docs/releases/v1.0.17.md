# Asgard Brigitte 1.0.17

The board's horizontal scrollbar is larger and easier to drag. The board and status bar remain inside the window when update reminders or warnings are displayed.

The [GitHub release](https://github.com/BenLampson/Asgard.Brigitte.Desktop/releases/tag/v1.0.17) provides the Windows x64 portable ZIP, unsigned Store-upload MSIX, checksums and source manifest. Extract the complete portable archive before running it; Microsoft Edge WebView2 Runtime is required. Exit any running instance, including from the system tray, before opening the portable build. The unsigned MSIX is for Store submission, not direct installation.

Both packages were built locally from clean, pushed commit `ff82d4a4f2b577a29550551d2d5bc5355799a5b6`, tagged `v1.0.17`. The portable ZIP SHA-256 is `a6244fd9f39e4866730b67dc3daa26c7239a3a77bd941ded18faf74a4551b18b`; the MSIX SHA-256 is `f42c525b9523345e5b53a30c5aee95edbc24354660695ab4448ff4c07cb04e80`. Package identity and matching CSS/UI/Core assemblies were checked; uploaded GitHub asset digests match.

All 289 local Core/UI tests passed. Browser checks used real mouse input to drag the scrollbar with and without simulated notices, in both themes and at multiple window sizes. Existing board lane-drag regression checks and [Windows/Linux CI tests and the Windows MAUI build](https://github.com/BenLampson/Asgard.Brigitte.Desktop/actions/runs/41548505717) also passed. Store-signed installation and upgrade, Windows App Certification Kit, and native desktop acceptance were not tested for this candidate. The optional symbol package was not generated because `mspdbcmf.exe` was unavailable.

Version 1.0.17.0 was formally submitted to Microsoft Store as Submission 17 (`1152921505702300983`) on November 3, 2026. Partner Center shows pre-processing in progress and is configured to begin publication after certification. Store availability of 1.0.17 is not yet confirmed. See the [Store submission log](../../packaging/windows/store-submission.md) for status.
