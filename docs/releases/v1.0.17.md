# Asgard Brigitte 1.0.17

The board's horizontal scrollbar is larger and easier to drag. The board and status bar remain inside the window when update reminders or warnings are displayed.

The local Core/UI test suite passed. Browser checks used real mouse input to drag the scrollbar with and without simulated notices, in both themes and at multiple window sizes. Existing board lane-drag regression checks also passed. Store-signed installation and upgrade, Windows App Certification Kit, and native desktop acceptance have not yet been verified for this version.
