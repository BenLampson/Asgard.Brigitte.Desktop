# Asgard Brigitte 1.0.1 — resubmission candidate

Prepared October 18, 2026. MSIX version: `1.0.1.0`, Windows x64. Formally resubmitted at approximately 14:35 Asia/Shanghai. Partner Center shows **In certification / pre-processing**, with publication configured to start immediately after approval. It is not yet published to Microsoft Store.

## Changes

- Each process start shows the welcome page. **Use on this computer / 本机使用** is the primary action and needs no account, sign-in, server deployment, or internet connection.
- Local projects, bugs, replies/work logs, status history, processing locks, attachment bodies, and repair prompts use a separate persistent SQLite workspace. Local records are not automatically uploaded or merged with online workspaces. No LAN service is included.
- Optional online collaboration retains the existing Heimdall/HTTP/synchronization flow. Local mode hides online account management, invitations, and MCP keys.
- Compact status/reply windows keep the title and Cancel/Save footer visible; the middle form scrolls when necessary.
- English/Chinese Store descriptions, reviewer steps, privacy/data documentation, and native local-mode screenshots accompany the candidate.
