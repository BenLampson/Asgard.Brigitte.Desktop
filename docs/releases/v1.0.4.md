# Asgard Brigitte 1.0.4

Prepared October 21, 2026. Windows x64, Microsoft Store package version `1.0.4.0`.

- Add Settings → Notifications with default rules and per-project overrides. Search by project name or code, mute noisy projects, or disable defaults and enable only the projects you follow.
- Choose which changes trigger in-app and system notifications: new bugs, status changes, claims and assignees, bug details, replies and work records, attachments, project changes, and bug removals.
- Filter status changes by their destination, such as Fixed or Closed. Any selected change type in a batch can trigger a notification; deselect other types to follow status changes only.
- Save preferences automatically on this device, separately for each service, tenant, and account. Muting keeps synchronization and unread activity intact. Re-enabling does not replay muted notifications.

## Upgrade compatibility

The package name, publisher, application ID, minimum Windows version, service endpoints, credential-storage keys, synchronization protocol, and existing SQLite schema remain unchanged from 1.0.3. Notification preferences use a new, separate device file. Without custom rules, notifications retain the previous behavior. No service deployment or database migration is required. Save drafts before installing an update; installation can close the app. Native Store installation/upgrade and Microsoft certification are separate from local tests and package validation.

Validation: 158 desktop tests passed, including rule persistence, identity isolation, structured notice classification, real Razor form interactions, and bilingual rendering. Windows MAUI compilation passed. Chinese/light and English/dark settings were checked in a browser, including the minimum window size.
