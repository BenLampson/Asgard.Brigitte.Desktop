# Asgard Brigitte 1.0.0

The first GitHub release of Asgard Brigitte includes the Windows x64 desktop client with English and Simplified Chinese, plus Microsoft Store submission materials.

**Microsoft Store status (updated October 18):** version `1.0.0.0` failed certification on October 17, 2026. The reviewer received `discovery_unavailable` before the credential form and could not access the workspace (10.1.2.10 and 10.3.1). A [local-first replacement](v1.0.1.md) is being prepared. The app is not yet available in Microsoft Store.

## What's included

- Project bug boards and lists, search and filters, independent editing and detail windows, Markdown, attachments, replies, and work logs.
- Project invitations, live sync, unread activity, a system tray, prompt copying, and scoped MCP key management.
- **Follow system / 简体中文 / English** in Settings → General → Language. Chinese system languages use Simplified Chinese; other languages use English. The choice is saved and updates open windows without clearing drafts. User content stays in its original language.
- English and Chinese privacy policies, support guides, and Store descriptions. Feedback and feature requests go to GitHub Issues; privacy requests use the email in the policy.
- System notification banners show update counts, while detailed collaboration summaries stay inside the app.

## Downloads

- **Windows x64 portable ZIP:** extract the complete archive to a folder you can write to, then run `Asgard.Brigitte.Desktop.exe`. Keep the bundled files together. The .NET and Windows App SDK runtimes are included; Microsoft Edge WebView2 Runtime is still required. This build is unsigned.
- **Store upload MSIX:** uses the registered Asgard Brigitte identity and version `1.0.0.0`, with `en-US` and `zh-CN` declared. It is **unsigned and intended for Partner Center upload**, not direct installation by ordinary users. Microsoft signs accepted Store packages.
- **SHA256SUMS.txt:** checksums for the downloadable ZIP and MSIX.
- **Store screenshots ZIP:** four English and four Simplified Chinese PNGs at 1600 × 900, captured from the actual release components with fictional sample data. The images are also available in [docs/screenshots](../screenshots).

Windows 10 version 1809 or later, x64, is required. An online compatible Brigitte service and account are required for sign-in and sync. Registration and access follow that service's rules. The client does not bundle a local server or an AI model. During a connection interruption, already synchronized content is read-only.

macOS sources are included, but no signed macOS binary is provided in this release. The Mac Catalyst host still needs a Mac build and platform validation.

Validation at release: 108 desktop tests passed, the Windows Release build passed, and Partner Center accepted the formal Store MSIX with the expected identity, languages, architecture, and version. A dedicated ordinary review account was used to exercise service sign-in, project and bug creation, a reply, and a harmless attachment in a synthetic workspace. The subsequent certification failed as described above. Windows App Certification Kit and clean-device installation/upgrade checks were not performed in that run.
