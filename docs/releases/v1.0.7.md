# Asgard Brigitte 1.0.7

Windows x64, Microsoft Store package version `1.0.7.0`. Prepared October 23, 2026 (Asia/Shanghai).

## Changes

The desktop board previously relied on native HTML drag-and-drop. Browser-only acceptance did not establish that the same drag gesture worked in the MAUI Hybrid host, and users reported that headers could not be moved. Lane headers now use pointer capture with a movement threshold. Dragging shows the entire lane as a floating shadow, leaves a faded placeholder, and marks the insertion position. Cards and attachment dragging remain separate.

Escape, pointer cancellation, lost capture, window focus loss, and releasing outside the board cancel without saving. Edge scrolling, Alt + Left / Right, reset, persisted account/project orders, and hidden-lane preservation remain supported.

## Verification

- All 195 desktop Core/UI tests passed in Release.
- Added a repeatable loopback-only browser regression host and real-mouse checks in `tests/browser/lane-drag/`. They cover the column shadow and insertion marker, click threshold, saved order after reload, Escape/outside cancellation, card exclusion, edge scrolling, filtered order preservation, keyboard movement and reset.
- An unpacked Windows Release build was launched in local mode. A separate synthetic project was created, and an actual mouse drag moved the reproducing lane before confirmed in the native MAUI/WebView2 window. No online workspace or production database was used.
- The final MSIX build and package provenance are recorded after packaging. Store installation/upgrade and WACK remain separate from this unpacked native acceptance.
