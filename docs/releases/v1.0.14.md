# Asgard Brigitte 1.0.14

Windows x64; Microsoft Store package version `1.0.14.0`.

- Known affected-service identifiers use localized names in the bug list, its tooltip and the bug detail view. For example, the Chinese interface displays `frontend` as “前端” and `backend` as “后端”.
- Custom service names and the stored values remain unchanged. The editor retains the original values for lossless editing.

Microsoft Store publication requires certification. The unsigned Store-upload MSIX is not a signed installer; see the [Store submission log](../../packaging/windows/store-submission.md) for the confirmed distribution status.
