# Asgard Brigitte 1.0.14

Windows x64; Microsoft Store package version `1.0.14.0`. The [GitHub release](https://github.com/BenLampson/Asgard.Brigitte.Desktop/releases/tag/v1.0.14) contains a portable ZIP, an unsigned Store-upload MSIX, checksums and a source manifest. Submitted to Microsoft Store as Submission 14 (`1152921505702294496`) on November 2, 2026. Partner Center shows pre-processing in progress; publication is set to begin after certification. Store availability of 1.0.14 is not yet confirmed. The preceding 1.0.13 submission is published.

- Known affected-service identifiers use localized names in the bug list, its tooltip and the bug detail view. For example, the Chinese interface displays `frontend` as “前端” and `backend` as “后端”.
- Custom service names and the stored values remain unchanged. The editor retains the original values for lossless editing.

The portable and Store packages were built locally from clean, pushed commit `03c386772f87cb27ca040cce36ca93d4b24e14bc`, tagged `v1.0.14`. The portable ZIP SHA-256 is `45693cf6cec823101d3ff57af4271bfc7d3a6dc3cfa8b2c39b2d9bd4b2c7a30c`; the MSIX SHA-256 is `f1aad44f23f8adc56b88829f618344bd6a0d5d552ca763749dd079574bb658cf`.

All 284 local Core/UI tests, including rendered list, detail and editor checks in both languages, and both Windows Release builds passed. [Source CI](https://github.com/BenLampson/Asgard.Brigitte.Desktop/actions/runs/41406916450) contains the Windows and Linux test results. Store-signed installation or upgrade, Windows App Certification Kit, and native desktop acceptance were not performed for this candidate. The optional symbol package was not generated because `mspdbcmf.exe` was unavailable.

Microsoft Store publication requires certification. The unsigned Store-upload MSIX is not a signed installer; see the [Store submission log](../../packaging/windows/store-submission.md) for the confirmed distribution status.
