# Asgard Brigitte 1.0.13

Windows x64; Microsoft Store package version `1.0.13.0`. The [GitHub release](https://github.com/BenLampson/Asgard.Brigitte.Desktop/releases/tag/v1.0.13) contains a portable ZIP, an unsigned Store-upload MSIX, checksums and a source manifest. Submitted to Microsoft Store as Submission 13 (`1152921505702292747`) on November 2, 2026. Partner Center shows pre-processing in progress; publication is set to begin after certification. Store availability of 1.0.13 is not yet confirmed. The preceding 1.0.12 submission is published.

- Work records show titles alongside full IDs for matching related bugs in the same project. Existing record text and statuses remain unchanged.
- Author, assignee and claimant displays retain IDs alongside verified names. When a name cannot be resolved, the interface says so instead of inventing one.
- These changes apply to local and synchronized workspaces without altering stored comments or workflow status.

The portable and Store packages were built locally from clean, pushed commit `f5bef81259e20c26a4b10d9f043dc2ca409322a1`, tagged `v1.0.13`. The portable ZIP SHA-256 is `d5ddfc233fc88fa8aae414edaf5ebdf39659dfd55ec488b7ce37f0bab1c79299`; the MSIX SHA-256 is `004430fce9c1d66a3795ad3cde211ab5475b291a61f91ac04853abc6e52f7a54`.

All 272 local Core/UI tests, the Windows Release builds and a browser-based component check passed. [Source CI](https://github.com/BenLampson/Asgard.Brigitte.Desktop/actions/runs/41383176509) passed its Windows MAUI build and Windows/Linux Core/UI tests. Store-signed installation or upgrade, Windows App Certification Kit, and native desktop acceptance were not performed for this candidate. The optional symbol package was not generated because `mspdbcmf.exe` was unavailable.

See the [Store submission log](../../packaging/windows/store-submission.md) for the current certification and distribution status. Microsoft Store certification and publication are separate from the GitHub release and local checks. The unsigned Store-upload MSIX is not a signed installer; the portable ZIP is available separately from GitHub Releases.
