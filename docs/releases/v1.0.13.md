# Asgard Brigitte 1.0.13

Windows x64; Microsoft Store package version `1.0.13.0`.

- Work records show titles alongside matching bug IDs from the same project, while preserving the original record and full IDs.
- Record authors and bug owners show verified account names and IDs. When a name is unavailable, the app says so instead of guessing.
- The changes apply to local and synchronized workspaces and do not alter stored comments or workflow status.

Microsoft Store publication requires certification. See the [Store submission log](../../packaging/windows/store-submission.md) for confirmed distribution status. The unsigned Store upload package is not a signed installer; the Windows portable ZIP is available separately from GitHub Releases.
