# Asgard Brigitte 1.0.18

Board lanes stay 240 CSS pixels wide when the window is resized. A wider window shows more lanes, and the remaining lanes can still be reached with horizontal scrolling. A single filtered lane keeps the same width.

The [GitHub release](https://github.com/BenLampson/Asgard.Brigitte.Desktop/releases/tag/v1.0.18) provides the Windows x64 portable ZIP, unsigned Store-upload MSIX, checksums and source manifest. Extract the complete portable archive before running it; Microsoft Edge WebView2 Runtime is required. Exit any running instance, including from the system tray, before opening the portable build. The unsigned MSIX is for Store submission, not direct installation.

Both packages were built locally from clean, pushed commit `0157decdd2d48177a6302073d4169d94d169a07e`, tagged `v1.0.18`. The portable ZIP SHA-256 is `7d8dc6d70936491c0658dca7c61c67448113c44deb3d8721cd2d6344cd399522`; the MSIX SHA-256 is `3957d445e42966cf9319b16bfa065f3119ba64cbc84a85aae8f3c8da5d4f8940`. Package identity and matching CSS/UI/Core assemblies were checked; uploaded GitHub asset digests match.

All 289 local Core/UI tests passed. Browser checks covered window resizing at four widths, single-status filtering, real mouse lane dragging and the horizontal scrollbar. [Windows/Linux CI tests and the Windows MAUI build](https://github.com/BenLampson/Asgard.Brigitte.Desktop/actions/runs/41664196493) passed. Store-signed installation and upgrade, Windows App Certification Kit and native desktop acceptance were not tested. The optional symbol package was not generated because `mspdbcmf.exe` was unavailable.
