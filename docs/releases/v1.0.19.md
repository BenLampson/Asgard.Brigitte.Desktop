# Asgard Brigitte 1.0.19

Image attachment previews now open in the system's default image application. PNG, JPEG, GIF and WebP remain available for preview; downloads continue to use the save dialog. Each preview uses an isolated temporary copy, and the app attempts to remove copies older than seven days the next time an image is previewed.

All 301 local Core/UI tests passed, including the preview button, attachment contents, safe filenames, cleanup and failure handling. The Windows desktop build passed. macOS native builds and runtime, Windows Store installation and upgrade, and Windows App Certification Kit have not been validated for this change.

The Microsoft Store package uses version `1.0.19.0`. Store submission and certification are separate from local build and test results; see the [submission log](../../packaging/windows/store-submission.md) for the confirmed status.
