# Asgard Brigitte 1.0.19

Image attachment previews now open in the system's default image application. PNG, JPEG, GIF and WebP remain available for preview; downloads continue to use the save dialog. Each preview uses an isolated temporary copy, and the app attempts to remove copies older than seven days the next time an image is previewed.

All 301 local Core/UI tests passed, including the preview button, attachment contents, safe filenames, cleanup and failure handling. The Windows desktop build and [Windows/Linux CI tests and Windows MAUI build](https://github.com/BenLampson/Asgard.Brigitte.Desktop/actions/runs/41859787967) passed. macOS native builds and runtime, actual default-app launch, Windows Store installation and upgrade, and Windows App Certification Kit have not been validated for this change.
