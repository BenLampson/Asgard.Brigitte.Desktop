# Asgard Brigitte 1.0.16

The main window automatically restores a saved Heimdall session at startup and then synchronizes the online workspace. When no online session can be restored, the welcome page provides local use and online sign-in. Explicit sign-out does not automatically start another login.

The [GitHub release](https://github.com/BenLampson/Asgard.Brigitte.Desktop/releases/tag/v1.0.16) provides the Windows x64 portable ZIP, unsigned Store-upload MSIX, checksums and source manifest. Extract the complete portable archive before running it; Microsoft Edge WebView2 Runtime is required. Exit any running instance, including from the system tray, before opening the portable build. The unsigned MSIX is for Store submission, not direct installation.

Both packages were built locally from clean, pushed commit `9112b1bbb24e463e6b763ba960e815a273ee9969`, tagged `v1.0.16`. The portable ZIP SHA-256 is `ca07433b8ecfd3413ff25448793b438a724c3fc679a020ae9b1497702ed525cb`; the MSIX SHA-256 is `46f790d57c7b5b64a480f5ca170af6be34443c724c4ac34db480980f8b88e23e`. Package identity and matching UI and Core assemblies were checked; uploaded GitHub asset digests match.

All 289 local Core/UI tests passed, including startup restoration, invalid credentials, service failure, secondary windows and explicit logout. [Windows and Linux CI tests and the Windows MAUI build](https://github.com/BenLampson/Asgard.Brigitte.Desktop/actions/runs/41464072290) passed.
