# Asgard Brigitte 1.0.11

Windows x64; Microsoft Store package version `1.0.11.0`.

- Replies and work logs show the newest record first. Each record can be expanded independently, and structured work logs distinguish their summary, changes, verification, delivery and follow-up. Existing Markdown remains readable.
- Project notification preferences also filter unread activity; project BUG statistics remain visible in the tray.
- Set lane order separately for each project, drag vertically, copy an order from another project after previewing it, or restore the default order. Keyboard reordering remains available.
- Device preferences move to SQLite on first use; old preference files are retained. Account credentials remain in secure storage.

Online structured records require a compatible server. Older servers and records continue to use their existing Markdown content. Store certification, Store-signed installation and native runtime acceptance are separate from local build and browser checks.

The x64 Store upload package was accepted and formally submitted for certification as Submission 11 on October 31, 2026. It is in pre-processing; release to customers begins after Microsoft certification. Version 1.0.10 was the published Store version when submitted. The upload MSIX SHA-256 is `12b2dab84fc4015c3dca2d71a2137474fe3947e2632693747a4edebea047e017`.

Built from source `81a690950c2ea057261d2d7c463e507099311437`; all 266 local Core/UI tests and the [Windows/Linux CI jobs](https://github.com/BenLampson/Asgard.Brigitte.Desktop/actions/runs/41183853289) passed. The [release assets](https://github.com/BenLampson/Asgard.Brigitte.Desktop/releases/tag/v1.0.11) include a portable ZIP, unsigned Store upload MSIX, checksums and a source manifest. A portable ZIP must be extracted before use and requires Microsoft Edge WebView2 Runtime.
