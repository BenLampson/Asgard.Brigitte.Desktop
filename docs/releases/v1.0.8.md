# Asgard Brigitte 1.0.8

Windows x64; Microsoft Store package version `1.0.8.0`.

## Changes

- Bug Management lets users select closed bugs across pages and save a ZIP containing SQLite and Excel backups before permanently deleting the selected bugs. If the selection changes after the backup is prepared, the user must create a new backup.
- An offline HTML report shows current project bug details and status and priority charts. Its content adapts to the available width with a five percent margin on each side.
- Online batch deletion requires a compatible server. Previously deleted bugs do not appear in subsequent reports; the report is not a historical billing ledger.

## Validation and distribution

Core/UI and server tests use synthetic local data and a dedicated test database. Store certification, installation and upgrade are separate checks from a successful local build. The Store upload package is unsigned for Microsoft to sign; use the portable ZIP for direct execution after extracting the complete archive.
