# 隐私与本地数据

本文说明客户端实现的数据流。连接的服务、第三方工具和发行者的实际政策应由相应运营方提供。

| 数据 | 位置与用途 |
| --- | --- |
| 登录凭据 | 平台 SecureStorage，供会话恢复及刷新；不写入业务 SQLite 或 JavaScript 存储 |
| 已授权项目、BUG、回复、历史与附件元数据 | 平台 AppDataDirectory 下的 `workspace` SQLite，按服务、租户及已验证用户隔离 |
| 未读动态 | 同一本地数据库；标记已读后删除相应通知记录 |
| 附件正文 | 按用户预览或下载操作请求；用户可另存到所选位置 |
| 主题和关闭偏好 | Windows 通常为 `%LOCALAPPDATA%/Asgard/Brigitte/` 下的 JSON 文件 |
| WebView 数据 | 平台应用数据目录中的 WebView 缓存；Windows 使用 `WebView2` 子目录 |
| 邀请令牌、邀请密码、一次性 MCP Key | 按操作短暂保留在内存中，不进入工作区同步投影 |

应用通过 Heimdall 获取账号标识、显示名称、租户和授权信息。项目内容、BUG、附件和操作记录发送到配置的 Brigitte 服务，并按该服务的项目权限共享。

退出登录删除当前凭据，阻止继续显示业务工作区。磁盘缓存、已另存的附件、系统通知历史和服务端数据可能仍保留。处理共享设备或删除账号数据时，需要同时考虑平台应用数据和服务方提供的删除渠道。

通知可能展示项目名、BUG 标题、操作人与变化摘要，可通过操作系统设置管理。最小化到托盘继续后台同步，完全退出则停止。

复制 AI 提示词不会自动向第三方发送内容。把提示词交给外部工具或向 MCP 客户端提供 Key 后，相应工具按你的操作及授权处理数据。报告问题前请移除凭据、邀请链接及真实工作区信息。
