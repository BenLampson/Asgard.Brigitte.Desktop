# Support for Asgard Brigitte

English · [简体中文](SUPPORT.zh-CN.md)

For bugs, feature requests, installation problems, or documentation questions, [open a GitHub Issue](https://github.com/BenLampson/Asgard.Brigitte.Desktop/issues/new/choose). English and Chinese are welcome. Search [existing issues](https://github.com/BenLampson/Asgard.Brigitte.Desktop/issues) first.

Include the application version, Windows version and architecture, app language, steps to reproduce, and expected and actual behavior. Add a screenshot or short log only after removing private information. Support is provided on a best-effort basis; a reply time is not guaranteed.

**GitHub Issues are public.** Never include passwords, tokens, full MCP keys, invitation links, private project content, account identifiers, or unredacted logs. Use synthetic example data when possible.

- Privacy, personal-data requests, and account deletion: [cn.benlampson@gmail.com](mailto:cn.benlampson@gmail.com). See the [privacy policy](PRIVACY.md). Do not send credentials.
- Security vulnerabilities: [report privately on GitHub](https://github.com/BenLampson/Asgard.Brigitte.Desktop/security/advisories/new). See [SECURITY.md](SECURITY.md).
- Access to a team's projects or administrator permissions: contact that project's owner or your service administrator. An issue report does not grant access.

The desktop client needs a compatible Brigitte service, an account, and network access to sign in and sync. Registration availability and project permissions depend on the service. A network interruption keeps synchronized content read-only; it does not queue offline edits. The client does not include a local server or an AI model. See the [usage guide](docs/usage.en.md).

To change language, open **Settings → General → Language** and choose **Follow system**, **简体中文**, or **English**. The default follows the operating system: Chinese system languages use Simplified Chinese, and other system languages use English. The preference applies immediately to open windows and is saved on the device.
